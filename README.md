# ARPG_GAS

****

Basic ARPG using Gameplay Ability System. The idea of the proyect is setting up a player with some general attributes and create an Combat Ability System. The combat system will be purely based on Abilities, allowing the player to select different ones and fight with them.
The idea is having a simple horde combat system, where the player first select different combat abilities and a comabt prototype and fight.
